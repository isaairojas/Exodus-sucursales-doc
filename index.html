Fundamentos

Principios de diseño

Exodus Handheld es una herramienta operativa de almacén y sucursal. El diseño prioriza claridad, toques grandes y lectura rápida bajo condiciones de trabajo.

touch_app

Táctil primero

Botones de 60 px y campos de 43–50 px. Objetivos amplios para operar con guantes o a ritmo de almacén.

ads_click

Una acción por pantalla

Flujo lineal. La acción primaria vive en una barra inferior fija; cancelar/rechazar siempre a la izquierda.

palette

Color con significado

Navy = marca y acción principal. Verde = confirmar. Rojo = cancelar, error o alerta. Sin decoración gratuita.

warning
Corrección respecto a la implementación actual. La app Exodus-sucursales-doc se construyó en tema oscuro con un navy distinto (#1a2b6b) y 11+ tonos de azul sueltos. Este Design System toma como fuente de verdad el prototipo real de Figma: tema claro, navy #1B3892 y paleta consolidada.

Cómo usar

Enlaza los dos CSS y usa las clases exo-*. Todo control debe ir dentro de un contenedor con la clase exo.

<link rel="stylesheet" href="tokens.css">
<link rel="stylesheet" href="components.css">

<div class="exo">
  <button class="exo-btn exo-btn--primary">Continuar</button>
</div>
